## 已知限制（逐条写明）

- **取消归档依赖两个官方内部形状**（`workspaceRegistry.enqueueOperation` 与 `state`）。DSH 升级可能失效，届时该能力被探测禁用而非静默出错。
- **agent 拆除依赖 cordis effect label 的精确字符串**。label 变动时插件拒绝删除，不会误删。
- **删除窗口期内会话可能被 UI 复活**：在 Web UI 里打开一个会话就会把它 resume 并重建目录。删除后会话已从所有列表消失，此风险已知并接受。
- **删除只支持 JSONL 会话持久化后端**（DSH 目前唯一的生产实现）。换用其他后端时删除能力被禁用，其余功能照常。
- **投影缓存 miss 时元数据降级**为会话 id 与创建时间；fork 出来的会话拿不到缓存快照。
- **「关闭所有运行中会话」的实际语义是释放后台占用**——宿主没有任何 idle 回收，而在 UI 里打开会话就会 resume 它。
- 安装后需检查 `~/.dsh/profiles/web/node_modules/@deepseek-ai/` 是否被 pnpm 复制成物理目录，那会导致核心包 Symbol 分裂。

## 明确说明不做什么

- 移除工作区不会自动归档其会话（宿主有意让它们落入未分组，本插件不改变该行为）
- 没有回收站、没有撤销窗口、没有定时清理；删除是终点
- 不向会话行菜单注入任何东西
